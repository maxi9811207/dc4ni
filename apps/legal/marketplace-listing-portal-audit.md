# Portal Audit - Marketplace Listing

## App Name
Portal Audit

## Tagline
See how everything connects. Map all dependencies between Forms, Lists, Workflows, and Properties in one click.

## Short Description (150 chars)
Scan your HubSpot portal to discover hidden dependencies, orphaned workflows, unused properties, and dead lists.

## Full Description

### The Problem
As your HubSpot portal grows, it becomes impossible to track how everything connects. Which workflows reference this form? Which lists will break if I delete this property? What workflows are still active but doing nothing?

Today, the only way to answer these questions is to manually click through every asset — or hire a consultant to do a portal audit for $2,000+.

### The Solution
Portal Audit scans your entire portal in under 60 seconds and gives you a complete dependency map:

**Dependency Mapping**
- See which Forms are used in which Lists and Workflows
- Identify the most connected (and most critical) assets
- Understand the blast radius before making changes

**Orphan Detection**
- Find workflows with no triggers or no actions
- Spot empty lists that nobody uses
- Identify inactive workflows that should be archived

**Property Audit**
- Custom properties not referenced in any workflow
- Potential cleanup candidates to reduce portal clutter

### Why Portal Audit?
- One-click scan — no configuration needed
- Results displayed natively inside HubSpot
- Perfect for quarterly portal cleanups
- Essential before any HubSpot migration
