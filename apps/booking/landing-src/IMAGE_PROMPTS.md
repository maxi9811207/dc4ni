# Digital Court 網站產品圖：GPT 生圖 prompt

網站：https://digital-court.cc/ 。共 **22 張**，全部用 **橫式 3:2（1536×1024）**。

## 怎麼用

1. 每張圖一個 prompt，整段複製貼到 ChatGPT（選「建立圖片」，比例選橫式 3:2）。
2. 存成 PNG，**檔名照下表**（例如 `ballwall.png`、`ballwall-scene.png`），放在同一個資料夾給我。
3. 我轉成 webp、放到 `landing/img/`，上線後頁面上的品牌底圖會自動換成你的圖，程式不用改。
4. 生出來的圖請先檢查：
   - 字要拼成 **Digital Court**，D 和 C 要比較大、比較粗、是深綠色。
   - 機台上不能有其他品牌的 logo 或亂碼文字。
   - 同一系列的外觀要一致：圓角綠色機櫃、厚邊框、頂上白色投影機、淺色原木配件。

> prompt 用英文寫，因為 GPT 生圖對英文的外觀描述比較準；每段最後都附上同一段「品牌設計規範」，整條產品線的外觀才會一致。
> 品牌字樣不滿意時，可以在同一個對話追加一句：「Make the capital D and C in "Digital Court" much bigger and bolder in lime yellow #E6F24A, keep the other letters thin white.」

## 外觀設計規範（2026-10-04 改成使用者指定的機櫃造型；已附在每段 prompt 最後）

- 造型：圓角、厚邊框的落地機櫃，像高級遊戲機台或展場互動機；螢幕內凹在邊框裡。
- 顏色：霧面深翠綠（#0B6B4B，略偏藍綠）機身、淺色原木配件（兩側平台、長椅、飾邊）、細白色 LED 邊線、黃綠色（#E6F24A）出球口與按鈕。
- 投影機：白色圓弧外殼，裝在機櫃上方的黑色短支架上。
- 品牌字樣：在機身下方面板。「Digital Court」的大寫 D 和 C 放大、特粗、黃綠色，其餘字母細白，讓「DC」自成字標；下面一行小字是產品名（PICKLEBALL、BALL WALL、CLIMB…）。
- 螢幕：發光綠色遊戲畫面，可以有「+10」這類大數字，不要其他文字。不能出現其他品牌 logo 或招牌字。
